Quick start

  1. 1

    Configure API

    copy .env.example .env
# Set OPENAI_API_KEY
  2. 2

    Build (first time)

    npm run install:continue
npm run build:vscode
  3. 3

    Launch

    npm start          # Mobius
npm run web        # This page (port 5173)
npm run sync:config # Push .env → Continue
Agent mode tip: In Continue sidebar, select Agent (not Chat). Chat mode has no tools and will ask questions instead of editing files.
