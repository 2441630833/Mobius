# Local OCR opt-in

## Root cause
OCR defaults to enabled in configuration, toolbar and request processing.
Disabling it currently forwards media even to models without vision support.

## Goal
Default OCR off and keep Web Search on. Ask to enable local OCR only when images
are attached to a model without declared vision support. Persist affirmative
consent; stop the image request on refusal. Videos require a multimodal model.

## Non-goals
Preserve explicit saved preferences and all initial unrelated submodule/xterm/
tmp-repro changes and the 2026-10-15-agent-terminal-cursor.md plan. Do not move
the existing v1.0.8 release tag.

## Tasks
1. [x] Update defaults, toolbar state and media consent routing.
2. [x] Typecheck and test consent decisions; commit and push scoped changes.

## Acceptance criteria
Fresh profiles show OCR off and Web Search on. Native vision bypasses OCR and
confirmation. Text-only requests do not prompt. Image requests to text models
require opt-in unless already enabled. Decline/cancellation never enables OCR.
