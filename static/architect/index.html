Mobius Agent Skill 路由架构

Phase 1 混合召回 + 意图域过滤 · Phase 2 Penalty-only 反馈

Phase 1 — 混合召回 + 意图域过滤

多路召回（Lexical + Embedding）→ 融合 → 意图域调整 → 纯向量降权 → 冲突过滤，最多 3 个兼容 skill。 向量 query 仅当前轮用户 prompt，不含 chat history。 

flowchart TD
  M[当前轮 prompt] --> L[Lexical Top-8]
  M --> E[Embed 当前轮]
  E --> S[Skill 向量索引]
  S --> A[Embedding Top-8]
  L --> F[0.45×embed + 0.55×lexical]
  A --> F
  F --> D[意图域调整]
  D --> G[纯向量降权 ×0.4]
  G --> P[F- penalty]
  P --> C[冲突过滤 Top-3]
组件文件
Embedding 索引 & 融合continueSkillEmbeddings.ts
路由、意图域、冲突过滤continueSkillsContext.ts
  • design-ui：设计页面 → frontend-design，屏蔽 wps/git 误载
  • document-ppt / document-word：单类型互斥，避免 PPT+Word 同载
  • quarterly-review.pptx 不再误触发 code-review

Phase 2 — Penalty-only 行为反馈

仅记录失败类 outcome 并施加 F-（0 ~ -3）。write_success 不记录、不加分——写文件成功不代表 skill 与 prompt 意图匹配。 

flowchart LR
  R[路由 skill] --> A[Agent 执行]
  A --> T{工具结果}
  T -->|write_file 成功| SKIP[跳过]
  T -->|失败/只探索/无工具| F[failure +1]
  F --> P[Storage]
  P --> B[F- 最多 -3]
